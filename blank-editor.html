General Mixed Assignment

Create a science assignment using ONLY the following markup. Output raw markup with NO preamble and NO code fences. FORMAT RULES: 1. TEXT BLOCKS: Use standard Markdown: - # Title, ## Heading, ### Subheading - **bold**, *italic*, [link](url) - Bulleted (- ) or Numbered (1. ) lists - Horizontal dividers: --- - MATH: Use LaTeX between $$ for blocks or $ for inline. Example: $$\frac{1}{2}$$ - TABLES: Use pipe format: | Col 1 | Col 2 | 2. IMAGES: ![alt](url) or ![alt](url "caption") 3. QUESTIONS: Must follow a two-line pattern: ## Question text here [q: type | config | points] Types: - [q: text] (Open text) - [q: choice | A. opt, B. correct*, C. opt | 100pts] (Mark correct with *) - [q: number | answer==VALUE | 100pts] (Operators: ==, !=, >, <, between MIN and MAX) - [q: text | contains "word" | 100pts] Separate sections with blank lines. Topic: [YOUR TOPIC HERE]

Multiple Choice Focused

Create a multiple choice quiz using ONLY the following markup format. Output only valid markup with NO preamble, NO explanations, and NO code fences. Format for each question: ## Question text here [q: choice | A. option, B. option, C. correct answer*, D. option | 100pts] Mark exactly ONE correct answer with * at the end of that choice. Separate each question with a blank line. Topic: [YOUR TOPIC HERE] Number of questions: [N]

Reading Passage + Comprehension

Create a reading passage and comprehension questions using ONLY the following markup. Output raw markup with NO preamble and NO code fences. 1. START with the reading passage. Use ## for a title, and standard Markdown (bold, lists, math) as needed. 2. FOLLOW with questions using the two-line format: ## Question Prompt [q: type | config | points] 3. TYPES: - [q: text] for analysis - [q: choice | A. opt, B. correct* | 100pts] for comprehension - [q: number | answer==X | 100pts] for data Topic: [YOUR TOPIC HERE] Reading level: [GRADE LEVEL]
