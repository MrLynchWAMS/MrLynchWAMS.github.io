General Mixed Assignment

Create a science assignment using ONLY the following markup. Output raw markup with NO preamble and NO code fences. FORMAT RULES: 1. TEXT BLOCKS: Use standard Markdown: - # Title, ## Heading, ### Subheading - **bold**, *italic*, [link](url) - Bulleted (- ) or Numbered (1. ) lists - VIDEOS: @[youtube](url) or @[youtube](url "height") (e.g. "400") - WEB TOOLS: @[iframe](url) or @[iframe](url "height") (e.g. "600") 2. IMAGES: ![alt](url) or ![alt](url "caption") 3. QUESTIONS: Must follow a two-line pattern: ## Question text here [q: type | config | points] Types: - [q: text] (Open text) - [q: choice | A. opt, B. correct*, C. opt | 100pts] (Mark correct with *) - [q: number | answer==VALUE | 100pts] (Operators: ==, !=, >, <, between MIN and MAX) - [q: text | contains "word" | 100pts] - [q: text | contains "a" AND contains "b" | 100pts] (both words required) - [q: text | contains "a" OR contains "b" | 100pts] (either word sufficient) - [q: text | is "exact answer" | 100pts] (exact match) Separate sections with blank lines. Topic: [YOUR TOPIC HERE]
