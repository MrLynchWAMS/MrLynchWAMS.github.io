General Mixed Assignment

Create a science assignment with mixed question types using ONLY the following markup format. Output only valid markup with NO preamble, NO commentary, and NO markdown code blocks — just the raw markup. Rules: - Text blocks: write plain text paragraphs - Images: ![alt](url) or ![alt](url "caption") - Open text questions: ## Prompt [q: text] - Number questions: ## Prompt [q: number | answer==VALUE | 100pts] - Range questions: ## Prompt [q: number | answer between MIN and MAX | 100pts] - Multiple choice: ## Prompt [q: choice | A. opt, B. opt, C. correct*, D. opt | 100pts] - Text contains: ## Prompt [q: text | contains "keyword" | 100pts] - The ## line is the question prompt; the [q: ...] line MUST immediately follow it - Separate questions with blank lines Topic: [YOUR TOPIC HERE]

Multiple Choice Focused

Create a multiple choice quiz using ONLY the following markup format. Output only valid markup with NO preamble, NO commentary, and NO markdown code blocks. Format for each question: ## Question text here [q: choice | A. option, B. option, C. correct answer*, D. option | 100pts] Mark exactly ONE correct answer with * at the end of that choice. Separate each question with a blank line. Topic: [YOUR TOPIC HERE] Number of questions: [N]

Reading Passage + Comprehension

Create a reading passage followed by comprehension questions using ONLY the following markup format. Output only valid markup with NO preamble, NO commentary, and NO markdown code blocks. - Start with a text block containing the reading passage (plain paragraphs) - Follow with comprehension questions - Text questions: ## Prompt [q: text] - Number questions (e.g. dates, quantities): ## Prompt [q: number | answer==VALUE | 100pts] - Multiple choice: ## Prompt [q: choice | A. opt, B. opt, C. correct*, D. opt | 100pts] - The ## line is the question prompt; the [q: ...] line MUST immediately follow it - Separate questions with blank lines Topic: [YOUR TOPIC HERE] Reading level: [GRADE LEVEL]
